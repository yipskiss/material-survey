# 재질 시각 평가 — 실험 사이트 사용설명서

재활용 플라스틱 20종(PL_1~20) + 종이 20종(P_1~20)을 라이트 박스 아래에서 시각 평가하는
실험용 사이트입니다. 피험자 40명(P01~P40), 재료당 4문항
(A1 종이처럼 보인다·A2 플라스틱처럼 보인다·A4 외관 선호: 리커트 7점 / A3 주된 재료: 객관식 종이·플라스틱·기타).
재료 사이에는 정면 주시 대기 화면, 20번째 재료 후에는 2분 휴식(카운트다운 종료 후 평가 시작 버튼 표시).

## 실험 당일 세팅

- **노트북** (진행자 자리): 탭 2개 — `#info`(참가자 인적사항 입력용), `#admin`(모니터링용)
- **태블릿**: 실험 링크. 피험자 선택 후 참가자에게 전달

### 참가자 1명 진행 흐름

1. 참가자 도착 → 노트북 `#info`에서 인적사항 입력 → 저장 → 진행자가 [다음 참가자 입력]으로 리셋
2. 태블릿에서 피험자 번호 선택 → 평가 시작 → 참가자에게 전달
3. 진행자는 노트북 `#admin`의 **제시 순서표**를 보며 시편 교체
   - 응답이 저장된 재료는 자동으로 흐려짐 (15초마다 갱신)
   - 칸을 탭하면 진행자 체크(✓) — 메모용, 데이터와 무관
4. 재료 40개 완료 → 태블릿 회수. 홈에서 해당 피험자는 초록 "완료"로 표시됨

## 제시 순서 (순환 라틴 스퀘어)

- P01 = 무작위 기준 순서. P02부터는 앞 피험자에서 **한 칸씩 밀린** 순서 (끝나면 처음으로 순환)
- 시편을 P01 순서로 줄 세워 두면, 피험자 번호 = 시작 위치
- 40명 전체로 보면 모든 재질이 모든 위치에 정확히 1번씩 제시됨 (위치 균형)
- 종이/플라스틱이 거의 교대로 제시됨 (같은 카테고리 최대 2연속)
- 전체 순서표: `제시순서_라틴스퀘어.xlsx` (시트1 = 기준 순서, 시트2 = 40명 매트릭스)

## 데이터

- **실험 응답**: 재료 하나 저장될 때마다 구글 시트 `responses` 탭에 한 줄씩 누적
  (피험자, 몇 번째, 재질 코드, 문항 9개 점수, 시각). 분석 시 시트에서
  파일 → 다운로드 → Excel(.xlsx)
- **인터넷 끊김**: 응답은 기기에 먼저 저장되고 연결되면 자동 재전송
  ("전송 대기 n건" 배너). 오프라인 동안 탭을 닫지 말 것
- **피험자 다시 실험**: 반드시 관리자의 [초기화] 버튼 사용 (시트+기기 동시 삭제).
  시트에서 행만 지우면 기기 기록이 남아 어긋남

## 참여비 지급 정보 (민감정보)

- `#info` 또는 관리자의 [＋ 정보 입력]으로 입력
- **관리자 키**(apps-script.gs의 ADMIN_KEY)를 입력한 기기끼리 목록이 공유됨
  (구글 시트 `participants` 탭에 저장, 실험 응답과 분리). 키가 없는 기기는
  그 기기에만 보관되다가, 키 연결 시 자동 전송
- 아이패드에서 인적사항을 받아도 키만 연결돼 있으면 노트북 관리자에서 바로 보임
- 내보내기 2종:
  - **CSV 수기입력용** — 주민번호 전체, 연구비 청구 화면의 입력 순서 그대로
    (성명→주민번호→소속→직위→활용일시→연락처→주소→청구금액→예금주→은행→계좌번호)
  - **CSV 증빙용** — 주민번호 앞 6자리-뒷자리 첫 숫자만, 계좌정보 한 칸으로 합침
- 화면 목록에는 마스킹된 주민번호만 표시. 청구 처리 후 [전체 삭제] 권장.
  기기 이동은 [JSON 백업]/[가져오기]

## 테스트 모드 (관리자 → 화면·테스트 설정)

| 조작 | 기능 |
|---|---|
| R | 현재 재질 랜덤 입력 (저장 안 함) |
| Space | 랜덤 입력 + 저장 + 다음 재질 |
| G | 자동 진행 시작/정지 (0.65초 간격으로 끝까지) |
| ← → | 대기 화면에서 재질 이동 (저장 안 함) |
| 관리자: 전체 랜덤 입력 | 선택 피험자의 남은 재료를 즉시 채움 (두 번 클릭) |

테스트 후: 해당 피험자 [초기화] → 테스트 모드 끄기. 설정은 기기별로 저장됨.

## 화면 설정

## 문제 해결

- **수정사항이 안 보임**: 강력 새로고침 (Ctrl+Shift+R / Cmd+Shift+R,
  아이패드는 주소 뒤에 `?v=2` 붙여 열기)
- **"시트 연결 안 됨"**: 인터넷 확인. 응답은 기기에 보관되니 계속 진행해도 됨
- **아이패드**: 일반 탭 사용 (사생활 보호 모드는 기기 저장이 약함)

## 구조 / 수정

- `index.html` — 사이트 전체 (GitHub Pages로 호스팅, push하면 1~2분 뒤 반영)
- `apps-script.gs` — 구글 시트 백엔드. **수정 시 Apps Script에 붙여넣고
  배포 → 배포 관리 → 새 버전으로 재배포해야 반영됨**
- 응답은 `responses_v2` 탭(4문항 버전)에 저장됨. API_KEY(응답용)와
  ADMIN_KEY(인적사항용)는 apps-script.gs와 클라이언트가 일치해야 함
- 문항·순서 데이터는 `index.html`의 `ITEMS` / `ORDERS`에 있음
